# Головна інструкція для Claude Code

Ми створюємо сучасну SaaS-платформу **Anexa Club** — приватну бізнес-спільноту для підприємців, фрилансерів, експертів, стартапів та творців.

## Основний принцип

Ми не створюємо окремі сторінки заради сторінок.
Ми будуємо масштабовану платформу, яка в майбутньому повинна витримувати десятки або сотні тисяч користувачів.

Перед створенням будь-якої нової функції потрібно:
- продумати її архітектуру;
- використовувати існуючі компоненти;
- не дублювати код;
- підтримувати єдиний стиль інтерфейсу;
- враховувати майбутнє масштабування.

## Пріоритет модулів

1. Feed — пости, реакції, коментарі, репости, закладки
2. Connections — підписки, контакти, рекомендації
3. Messages — чати, приватні повідомлення, онлайн-статус
4. Notifications — центр сповіщень
5. Search — глобальний пошук
6. Events — створення, реєстрація, календар
7. Communities — групи, адміни, модератори
8. Companies — профілі компаній, вакансії

Ядрові платні модулі (Marketplace, Баланс, Донати, AI, Premium, Курси,
Платежі, Реферальна система, Гарант угод) — після готовності основного
функціоналу.

## Якість коду

Кожен модуль: production-ready, масштабований, типізований, з перевіркою
помилок і адаптивністю. Не поспішати — переходити до наступного модуля
лише після завершення попереднього.
